# Cooooooooooins!

<img src="logo.png" width="150" alt="the mod's logo" />

A mod that adds 10 coins to the main levels

The levels were created by people who helped me ensure that the available levels have paths that allow for 10 coins to be placed and remain playable

If the project gets some support, we’ll probably be motivated to keep making more levels so we can complete all 22 main levels! *(At the moment, we’re not sure if the platformer levels will be fun to make, so it’s not in our plans just yet)*
